целевая температура уйдёт в device-service для устройства 3f1c2a9e…

Монолит :8080 — датчики (значение температуры пишет хаб через API монолита)

Device Service :8002 — устройства (device-api.yaml)

Telemetry Service :8003 — последние показания (через RabbitMQ)

Iframe обновляются каждые 3 секунды. Кнопки отправляют POST /control/ в API Gateway → gateway ставит команду в очередь device-service → хаб забирает её через GET /commands/ при следующем опросе и применяет (turn_on / turn_off для света, set_temperature с params.target для термостата) → состояние устройства меняется.
